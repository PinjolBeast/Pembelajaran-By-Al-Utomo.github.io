🌟 Pembelajaran Dasar HTML & CSS

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup untuk membuat struktur halaman web. Bayangkan seperti kerangka rumah - HTML menyediakan fondasi, sementara CSS dan JavaScript menambah estetika dan interaktivitas.



  
  

Elemen HTML Dasar

Heading (Judul)

Heading digunakan untuk judul dengan berbagai tingkatan:

Ini H1 - Paling Besar

Ini H2 - Sedikit Lebih Kecil

Ini H3 - Masih Lebih Kecil

Paragraph (Paragraf)

Ini adalah paragraf. Paragraf digunakan untuk teks panjang yang terbaca.

Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa untuk mengatur tampilan HTML. Tanpa CSS, halaman web akan terlihat sangat sederhana dan tidak menarik.

/* CSS untuk mengubah warna teks */
h1 { color: blue; }
/* CSS untuk background */
body { background-color: lightgray; }

Kenapa Kita Perlu JavaScript?

HTML dan CSS membuat halaman web statis. JavaScript menambah interaktivitas - seperti tombol yang bisa diklik, form yang bisa disubmit, dan konten yang berubah secara dinamis.

Pertanyaan untuk Anda: Bayangkan website tanpa JavaScript - apa yang tidak bisa Anda lakukan?

Struktur File Web

  • HTML: Struktur dan konten
  • CSS: Styling dan layout
  • JavaScript: Interaktivitas dan logika

Analoginya seperti: HTML = kerangka rumah, CSS = cat dan dekorasi, JavaScript = listrik dan peralatan yang membuat rumah "hidup".
