Pembelajaran Keamanan Web

Lengkap untuk Pemula - Dari Dasar hingga Praktik Terbaik

Apa itu Keamanan Web?

Keamanan web adalah praktik melindungi website dari ancaman seperti hacking, malware, dan serangan cyber. Tanpa keamanan yang baik, data pengguna bisa dicuri atau website bisa diretas.

💡 Tips Penting: Keamanan web bukan hanya untuk website besar. Setiap website, bahkan yang sederhana, perlu dilindungi agar aman digunakan.

HTTPS dan Sertifikat SSL

HTTPS (HyperText Transfer Protocol Secure) adalah versi aman dari HTTP. SSL/TLS sertifikat mengenkripsi data yang dikirim antara browser dan server.

⚠️ Peringatan: Jangan pernah kirim data sensitif (password, kartu kredit) melalui HTTP biasa. Selalu gunakan HTTPS!

SQL Injection - Ancaman Umum

SQL Injection terjadi ketika hacker memasukkan kode SQL berbahaya ke dalam form input. Ini bisa menghapus atau mencuri data dari database.

/* Contoh kode rentan SQL Injection (JANGAN DIGUNAKAN!) */ $query = "SELECT * FROM users WHERE username = '" . $_POST['username'] . "'"; /* Cara aman menggunakan Prepared Statements */ $stmt = $pdo->prepare("SELECT * FROM users WHERE username = ?"); $stmt->execute([$_POST['username']]);

XSS (Cross-Site Scripting)

XSS terjadi ketika hacker memasukkan script berbahaya ke dalam website yang ditampilkan kepada pengguna lain. Ini bisa mencuri cookie atau mengubah tampilan halaman.

🛡️ Pencegahan XSS: 1. Escape semua output user
2. Gunakan Content Security Policy
3. Validasi input di sisi server

CSRF (Cross-Site Request Forgery)

CSRF memaksa pengguna yang sudah login untuk melakukan aksi tanpa sadar, seperti mengubah password atau mentransfer uang.

Keamanan Password

Password yang lemah adalah pintu masuk utama hacker. Gunakan password kuat dan hash yang aman.

// Hash password dengan bcrypt (PHP) $hashed_password = password_hash($password, PASSWORD_DEFAULT); // Verifikasi password if (password_verify($password, $hashed_password)) { // Login berhasil }

Keamanan Upload File

Upload file bisa menjadi celah keamanan jika tidak dikontrol. Hacker bisa upload file berbahaya seperti virus atau script.

/* Validasi file upload (PHP) */ $allowed_types = ['image/jpeg', 'image/png']; $max_size = 2 * 1024 * 1024; // 2MB if (!in_array($_FILES['file']['type'], $allowed_types)) { die('Tipe file tidak diizinkan'); } if ($_FILES['file']['size'] > $max_size) { die('File terlalu besar'); }

Praktik Terbaik Keamanan Web

  • Update Software: Selalu update framework, library, dan server
  • Backup Rutin: Backup data penting secara berkala
  • Monitoring: Pantau log server untuk aktivitas mencurigakan
  • Edukasi: Latih diri tentang ancaman keamanan terbaru
  • Principle of Least Privilege: Berikan akses minimal yang diperlukan

Tools untuk Testing Keamanan

Ada banyak tools gratis untuk memeriksa keamanan website Anda:

  • OWASP ZAP: Scanner keamanan web open source
  • Burp Suite Community: Proxy untuk testing manual
  • Nmap: Scanner port dan service
  • SSL Labs: Test kekuatan SSL/TLS
