Selektor Dasar

Selektor Elemen
Memilih elemen HTML berdasarkan nama tag.
/* Selektor elemen - memilih semua elemen p */ p { color: blue; }

Contoh paragraf dengan warna biru.

Selektor Class
Memilih elemen berdasarkan atribut class.
/* Selektor class - memilih elemen dengan class "highlight" */ .highlight { background-color: yellow; }
Teks yang disorot.
Selektor ID
Memilih elemen unik berdasarkan atribut id.
/* Selektor ID - memilih elemen dengan id "header" */ #header { font-size: 24px; }

Judul dengan ID

Warna dan Latar Belakang

Warna Teks (color)
Mengubah warna teks elemen.
Nilai: nama warna (red), hex (#ff0000), rgb(255,0,0), hsl(0,100%,50%)
/* Mengubah warna teks menjadi merah */ p { color: red; }

Teks berwarna merah.

Latar Belakang (background)
Mengatur latar belakang elemen.
Nilai: warna, gambar, gradien
/* Latar belakang dengan gradien */ div { background: linear-gradient(to right, #ff0000, #0000ff); }
Gradien latar belakang

Properti Teks

Ukuran Font (font-size)
Mengatur ukuran teks.
Nilai: px, em, rem, %
/* Ukuran font 20px */ h1 { font-size: 20px; }

Judul dengan ukuran 20px

Ketebalan Font (font-weight)
Mengatur ketebalan teks.
Nilai: normal, bold, 100-900
/* Teks tebal */ strong { font-weight: bold; }
Teks tebal
Jarak Baris (line-height)
Mengatur jarak antar baris teks.
Nilai: angka (1.5), px, em
/* Jarak baris 1.5 */ p { line-height: 1.5; }

Paragraf dengan jarak baris 1.5. Ini membuat teks lebih mudah dibaca dengan memberikan ruang yang cukup antara baris.

Model Kotak (Box Model)

Margin
Ruang di luar border elemen.
Nilai: px, em, auto
/* Margin 10px di semua sisi */ div { margin: 10px; } /* Margin berbeda untuk setiap sisi */ div { margin-top: 10px; margin-right: 20px; margin-bottom: 10px; margin-left: 20px; }
Kotak dengan margin 20px
Padding
Ruang di dalam border elemen.
Nilai: px, em, %
/* Padding 15px di semua sisi */ div { padding: 15px; }
Kotak dengan padding 15px
Border
Garis tepi elemen.
Nilai: width style color (contoh: 2px solid black)
/* Border solid 2px hitam */ div { border: 2px solid black; } /* Border radius untuk sudut melengkung */ div { border-radius: 10px; }
Kotak dengan border dan border-radius

Display dan Visibility

Display
Mengatur bagaimana elemen ditampilkan.
Nilai: block, inline, inline-block, none, flex, grid
/* Elemen block - mengambil lebar penuh */ div { display: block; } /* Elemen inline - hanya mengambil ruang yang dibutuhkan */ span { display: inline; } /* Sembunyikan elemen */ .hidden { display: none; }
Elemen block
Elemen inline
Visibility
Mengatur visibilitas elemen tanpa menghapusnya dari layout.
Nilai: visible, hidden
/* Sembunyikan elemen tapi tetap ada di layout */ .invisible { visibility: hidden; }
Elemen tersembunyi (masih mengambil ruang)

Posisi

Position
Mengatur posisi elemen.
Nilai: static, relative, absolute, fixed, sticky
/* Posisi relatif - relatif terhadap posisi normal */ .relative { position: relative; top: 10px; left: 20px; } /* Posisi absolut - relatif terhadap parent yang diposisikan */ .absolute { position: absolute; top: 0; right: 0; }
Kotak relatif
Absolut
Z-index
Mengatur urutan stacking elemen.
Nilai: angka (bilangan bulat)
/* Elemen dengan z-index lebih tinggi akan di atas */ .front { z-index: 10; } .back { z-index: 1; }
Belakang
Depan

Flexbox

Display: Flex
Mengaktifkan flexbox pada container.
/* Container flex */ .container { display: flex; }

Justify-content
Mengatur penyebaran item secara horizontal.
Nilai: flex-start, center, flex-end, space-between, space-around
/* Item rata tengah */ .container { display: flex; justify-content: center; }
Align-items
Mengatur penyebaran item secara vertikal.
Nilai: flex-start, center, flex-end, stretch
/* Item rata tengah vertikal */ .container { display: flex; align-items: center; }

CSS Grid

Display: Grid
Mengaktifkan grid pada container.
/* Container grid */ .container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }

Grid-template-columns
Mendefinisikan kolom grid.
Nilai: ukuran kolom (px, fr, %)
/* 3 kolom dengan ukuran sama */ .container { grid-template-columns: 1fr 1fr 1fr; } /* Kolom dengan ukuran berbeda */ .container { grid-template-columns: 200px 1fr 200px; }

Desain Responsif

Media Queries
Mengubah style berdasarkan ukuran layar.
/* Untuk layar kecil (ponsel) */ @media (max-width: 768px) { .container { padding: 10px; } h1 { font-size: 24px; } }
Ubah ukuran jendela browser untuk melihat efek responsif!

Animasi dan Transisi

Transition
Membuat perubahan properti menjadi halus.
/* Transisi pada hover */ .box { background: blue; transition: background 0.5s; } .box:hover { background: red; }

Arahkan kursor ke lingkaran di atas untuk melihat transisi!

Animation
Membuat animasi kustom.
/* Definisi animasi */ @keyframes bounce { 0% { transform: translateY(0); } 50% { transform: translateY(-20px); } 100% { transform: translateY(0); } } /* Menggunakan animasi */ .bounce { animation: bounce 1s infinite; }

Lingkaran hijau di atas menggunakan animasi bounce!
